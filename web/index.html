Data & methodology

Source: cached OneBusAway transit data and Seattle SDCI building permits. The corridor is the union of ⅓-mile buffers around directional stops; physical stops group platforms within 500 feet using shared parent stations or matching normalized intersection names, including abbreviations and missing qualifiers. Differently named platforms within 250 feet can merge with opposite-direction evidence. Every pair in a group must qualify; combined labels retain the original names. Unmatched stops remain individually selectable. Comparison numbers follow the selected direction’s source stop order, or metric ranks when sorted by value. Combined order appends additional branch stops. Buffers show straight-line distance, not a walking network.

Qualifying permits are issued, active building permits for new construction or major alterations (housing changes or at least $1 million estimated cost). Permit counts include dependent records. Projects consolidate primary permits by normalized address, description, type, cost and housing outcomes. Each project and permit starts at the nearest boarding stop within ⅓ mile in each available feed destination group. Around substantial bends, a bounded heuristic can prefer a later stop within 330 extra straight-line feet and the same radius. This is an estimate, not a journey-time recommendation. Assignments then map to physical stops. Combined directions can overlap; route and physical-stop totals count each record once. Directional polygons use the same departure preference as assignments; shared-boundary ties follow physical-stop order. These straight-line areas ignore walking barriers and are not walking catchments.

Date filters use permit issue dates and each consolidated project’s earliest issue date. Missing unit and value fields contribute zero to sums; they do not establish that no change occurred. Net units = gross added − removed. Estimated value is the reported permitting estimate, not assessed value or actual investment. Permitted housing is not necessarily completed housing. Cached data is a snapshot. Use Refresh selected source to retrieve current transit, permit or street data. Permit downloads can take a few minutes. Seattle permit coverage does not extend to all King County routes.

Statuses describe current cached primary-permit records, not historical status or verified building occupancy. Mixed-use and institutional labels are description-based hints; residential-only use is not assumed.
